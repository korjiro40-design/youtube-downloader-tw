# YouTube 下載器・繁體中文版

Windows 可攜式圖形介面下載器，底層使用 yt-dlp 與 FFmpeg。

## 功能

- 繁體中文介面
- 單部 YouTube 影片與播放清單
- MP4 最佳畫質、1080p、720p
- MP3 高音質
- 播放清單自動依序編號
- 顯示下載進度
- 下載失敗自動重試
- 單一 EXE，可攜使用
- 使用端不需要安裝 Python

## 取得 Windows 可攜版

進入 GitHub 的 **Actions** → **建置 Windows 可攜版** → 最新成功執行紀錄 → 在 **Artifacts** 下載 `YouTube下載器-Windows-可攜版`。

解壓縮後直接雙擊 `YouTube下載器.exe`。

## 使用方式

1. 貼上影片或播放清單網址。
2. 選擇 MP4 或 MP3。
3. 選擇儲存資料夾。
4. 按「開始下載」。

> 請遵守網站服務條款與著作權規範，僅下載你有權保存的內容。
